# 🖼️ Image Slider
## JavaScriptHTML5CSS3

## 📌 Description
An interactive image slider that automatically cycles through images with a smooth transition, while also allowing users to manually navigate between them at their own pace.

## ✨ Features
- ⚡ Smooth automatic image transition (Auto-play).
- ⬅️➡️ Manual navigation using Next and Previous buttons.
- 🎯 User interaction pauses the auto-play to give full control.
- 💻 Note: Currently optimized for Desktop. Mobile responsiveness will be added in a future update.
- 🛠️ Tech Stack
- HTML5 (Structure)
- CSS3 (Styling & Animations)
- Vanilla JavaScript (DOM Manipulation & SetInterval)
